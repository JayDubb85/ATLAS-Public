# ATLAS · Public issue tracker

Bug reports and feature requests for **ATLAS**, the independent Crimson Desert companion by **Dubb**.

ATLAS is in development. This repository hosts community reports and suggestions; it does not contain the application source code or a public app download.

## Report an issue

1. [Search existing reports](https://github.com/JayDubb85/ATLAS-Public/issues) to see whether someone has already reported it.
2. [Open a bug report or feature request](https://github.com/JayDubb85/ATLAS-Public/issues/new/choose).
3. Include the ATLAS build, Windows version, steps to reproduce, and expected versus actual behavior. For game-data issues, include the game version when known.

Reports and attachments are public. Do not post credentials, personal information, or game saves. For sensitive reports or help without a GitHub account, email **creations@dubb.gg** and mention ATLAS.
